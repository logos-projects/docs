## preclobcore
A high-performance, in-memory Central Limit Order Book (CLOB) matching engine written in Rust, designed to handle binary prediction markets at scale. Built for deterministic, crash-recoverable, low-latency order matching with NUMA-aware CPU affinity and lock-free data structures.
